# Mary Tuvei — Portfolio

Personal portfolio for Mary Tuvei, aimed at social media / media manager, virtual & executive assistant, and AI evaluation roles.

Built with Next.js (App Router) and TypeScript, no other runtime dependencies.

## Edit content
All text lives in `app/data.ts`. The AI-evaluation sample is in `app/page.tsx`. The résumé PDF is `public/Mary_Tuvei_Resume.pdf`.

## Run locally
```bash
npm install
npm run dev
```

## Deploy
Hosted on Vercel. Redeploy with `vercel --prod` or push to a connected Git repo.
